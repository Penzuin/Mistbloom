## Description

**Night Wings** is a set of six wing cosmetics for HMCCosmetics. They go in the backpack
slot, they're animated, and each pair has a few small 3D bits (claws, crystals, a gold
clasp, a flower bud) so they don't look like flat cutouts from the side.

**The wings**
- **Starfeather** - soft pearl feathers with gold trim. Dyeable, the trim stays gold.
- **Duskbat** - leathery bat wings with torn edges and a red glow.
- **Frostlight** - glowing ice with a little crystal cluster on the back.
- **Bloomfairy** - shimmery fairy wings with a tiny fairy body in the middle.
- **Nightwyrm** - dragon wings with green veins, claws and a spine plate.
- **Mistbloom Petal** - night flower petals around a glowing bud.

**What's in the download**
- Ready-to-drop folders for **Nexo, ItemsAdder and Oraxen**, plus a plain resource pack
  if you don't use an items plugin
- HMCCosmetics cosmetics file and a menu (`/cosmetic menu night_wings`)
- A permission per pair, like `hmccosmetics.frostlight_wings`, so they're easy to use
  as rank perks or crate rewards
- Blockbench files with named parts, if you want to move or resize anything
- A README with install steps for each plugin

**Performance:** 12 cubes or fewer per model and one texture each. The animation is all
texture-based, so your server doesn't do any extra work.

**Requirements:** Paper or Purpur 1.21.4+, HMCCosmetics 2.9+, and Nexo, ItemsAdder 4 or
Oraxen (or none of them, using the included resource pack).
