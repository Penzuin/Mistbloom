Rosewick Garden - Mistbloom Studios
==================================================

14 cottage-garden furniture pieces: a rose arbor, benches and a tea table, potting and seed storage, a birdbath, a wheelbarrow of blooms and a stake lantern you can light.

INSTALL - Drag and Drop (Nexo)
--------------
1. Copy Nexo/items/rosewick_garden.yml into plugins/Nexo/items/
2. Copy the Nexo/pack/assets/ folder into plugins/Nexo/pack/assets/
3. Optional: copy Nexo/recipes/shaped/rosewick_garden.yml into plugins/Nexo/recipes/shaped/ to let players craft the pieces.
4. Run /nexo reload all, then /nexo inventory to grab the pieces.

Requires Minecraft 1.21.4 or newer
