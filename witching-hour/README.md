# Witching Hour v1.0

Six witchy cosmetics for HMCCosmetics that work all year: Moonlit Witch Hat, Candle Crown,
Ghostlight Lantern, Moon Grimoire, Wisp (balloon) and Moonlit Broom.

- `Mistbloom_Witching_Hour_v1.0.zip` - the pack you sell
- `LISTING.md` - store title, description and image order
- `listing/` - store images and spin GIFs
- `src/` - the scripts that make it: `pieces.py` (models) -> `preview.py` -> `listing.py` -> `build.py`

Not tested in-game yet. Check the wisp's height (`balloon-offset`) and how the lantern and
grimoire sit in the off-hand on the Selling Test server first.
