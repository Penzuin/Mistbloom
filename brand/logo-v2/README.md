# Mistbloom Studios logo (v2)

Name made with Ewan Howell's Minecraft Title Generator plugin for Blockbench.

- Font: Minecraft Ten (plugin default), default border and depth
- MISTBLOOM: gradient #F4EEFF -> #C9B8F0 -> #7A64CC
- STUDIOS: Small text, gradient #FFF6D8 -> #F2C97D -> #C8903F
- Flower: the original Mistbloom mark, unchanged
